# Pneumonia Detection System

A Deep Learning assignment to detect Pneumonia from chest X-ray images using Transfer Learning (MobileNetV2) and Streamlit.

## 📂 Project Structure
- **`app.py`**: The Streamlit user interface.
- **`train.py`**: The model training script (includes auto-download of dataset).
- **`requirements.txt`**: Project dependencies.
- **`model.h5`**: The trained AI model (generated by `train.py`).

## 🚀 Setup & Usage

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Train Model
Run the training script. It will **automatically download** the Pneumonia dataset from Kaggle and train the model.
```bash
python train.py
```
> **Note**: This may take a few minutes to download the data and train.
> The model is saved as `model.h5` with a size < 25MB (optimizer excluded).

### 3. Run Application
Launch the web interface:
```bash
streamlit run app.py
```

---

## 📘 Project Documentation

### Model Details
- **Architecture**: MobileNetV2 (Transfer Learning).
- **Base**: Pre-trained on ImageNet (frozen).
- **Head**: GlobalAveragePooling2D → Dense(64) → Dropout(0.5) → Softmax.
- **Size Optimization**: Saved without optimizer state to meet the < 25MB assignment limit (approx 9.5MB).

### Application Flow
1. **Upload**: User uploads a chest X-ray.
2. **Preprocessing**: Image resized to 224x224 and normalized.
3. **Inference**: Model predicts 'Normal' vs 'Pneumonia'.
4. **Output**: Shows prediction, confidence score, and probability chart.
